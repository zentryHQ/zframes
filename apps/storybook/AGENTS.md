# apps/storybook

Every frame in isolation, across all variants and states, at :6006.

a Storybook (port 6006) that renders **every frame in isolation, across all variants and states**, for fast visual testing. It feeds a one-frame `DashboardSpec` to the real `DashboardRenderer` (so chrome, `--zf-*` theme vars, and the error/loading paths match production) wrapped in `FramesProvider` with a deterministic, **offline** `MockMarketDataProvider` (`@zframes/provider-demo`) instead of live data — the provider advertises every capability and has four modes (`normal`/`loading`/`empty`/`error`). `scripts/gen-stories.ts` generates one `src/stories/<frame>.stories.tsx` per frame on `predev`/`prebuild` (enumerated from the React-free `@zframes/frames/schemas` so it covers the **full** set, not the curated `frameMetas` subset). Each frame gets six stories: **Default** (Controls auto-derived from its Zod schema), **AllVariants** (every enum/boolean/curated config in a grid), **AllSizes** (the frame at every grid span it can be resized to — the full `layout.minW/maxW × minH/maxH` envelope the editor writes as GridStack's `gs-min-w`/`gs-max-w`, clamped to the board's 12 columns and capped at 72 cells; heights default to 6 rows where `maxH` is open, since a board grows downward forever), **OutOfBounds** (the ring of spans the envelope FORBIDS — one step under each floor, one step over each ceiling, each labelled with the bound it breaks; every cell is *meant* to look wrong, and the test is whether it fails gracefully rather than silently, so a cell that looks fine means the bound is too strict and should be re-measured), **States** (the four provider modes), and **Live**. **Live is the one story that leaves the mock behind**: it renders against the real `createKeylessProviders()` set (built ONCE per browser session in `src/live-providers.ts` — a per-story set would open a Hyperliquid WS each time and re-fetch past every provider's instance-scoped `TtlCache`), so a frame can be eyeballed against the shape real upstream data has. Two consequences: `.storybook/main.ts` mounts the same-origin **`/__zframes/proxy`** route via `handleProxy` (dev server only — without it the ~third of providers reading CORS-blocked official hosts render *empty*, which reads as a frame bug; a static `storybook-build` has no such route, so Live degrades there), and Live is non-deterministic, so it is never a visual-regression target — `frame-render-smoke.ts` pins `RENDER_STORY` to `Default`. Keyed providers stay out: `providers-keyless` never imports them. A toolbar switches **theme preset / frame size / density** globally. Curated bases/variants live in `src/curated.ts`; the universal config seed reuses the editor's `buildDefaultConfig` via the `@zframes/editor/editor-symbols` subpath. Generated `src/stories/` and `storybook-static/` are gitignored.
